Shadow Sprint - Result Screen Fix (VS2013)
===========================================

Result screens use the existing game variables:
  FINAL SCORE        -> score
  COINS COLLECTED    -> coinCount

The live numbers are rendered larger and placed after the labels.

Mouse click areas (800x400 game window, bottom-left OpenGL coordinates):

EASY GAME OVER (easy1.jpg)
  RETRY : x 220..400, y 50..120
  QUIT  : x 410..592, y 50..120

EASY LEVEL COMPLETE (easy2.jpg)
  RETRY          : x 226..405, y 50..120
  RETURN TO CAMP : x 417..596, y 50..120

MEDIUM GAME OVER (medium1.jpg)
  HOME  : x 296..388, y 0..72
  RETRY : x 416..506, y 0..72

MEDIUM LEVEL COMPLETE (medium2.jpg)
  HOME        : x 296..388, y 0..72
  RETRY LEVEL : x 416..507, y 0..72

Why the Y values look different:
The iGraphics mouse callback converts the Windows top-left mouse Y
coordinate to OpenGL bottom-left coordinates before iMouse() receives it.
The ranges above therefore match the actual visible button locations.

VS2013:
  Open ShadowSprint_VS2013.sln
  Select Debug / Win32
  Rebuild Solution
  Press F5
